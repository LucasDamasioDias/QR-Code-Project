# QR Code Project

## 📌 Descrição
Este projeto foi desenvolvido para a geração de QR Codes e senhas seguras para e-commerce. A aplicação permite a criação de códigos QR dinâmicos e a geração de senhas fortes, auxiliando na segurança e na usabilidade das transações online.

## 🚀 Tecnologias Utilizadas
- **Node.js** - Ambiente de execução JavaScript

## 📂 Estrutura do Projeto
```
QR-Code-Project/
├── src/
│   ├── qrcode.js  # Lógica de geração de QR Codes
│   ├── password.js  # Lógica de geração de senhas seguras
├── index.js  # Arquivo principal da aplicação
├── package.json  # Dependências e scripts
├── README.md  # Documentação do projeto
```

## 🔧 Instalação e Execução
### 1️⃣ Clone o repositório:
```bash
git clone https://github.com/LucasDamasioDias/QR-Code-Project.git
```

### 2️⃣ Acesse o diretório do projeto:
```bash
cd QR-Code-Project
```

### 3️⃣ Instale as dependências:
```bash
npm install
```

### 4️⃣ Execute o projeto:
```bash
npm run start
`
